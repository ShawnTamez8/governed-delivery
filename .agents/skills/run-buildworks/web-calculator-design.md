# Product Requirements Document (PRD)

## Project Name

Web Calculator

## Purpose

Create a browser-based calculator that allows users to perform common
arithmetic calculations through an intuitive user interface. The application
shall support both light and dark themes and function entirely within a web
browser without requiring installation.

## Goals

- Provide basic calculator functionality.
- Deliver a fast and responsive user experience.
- Support both desktop and mobile browsers.
- Support user-selectable dark and light themes.
- Maintain accessibility and usability standards.

## Target Users

- General users needing quick calculations.
- Students.
- Office workers.
- Users accessing the application from desktop or mobile devices.

## Scope

### Included

- Basic arithmetic operations
- Decimal calculations
- Dark and light modes
- Responsive web interface
- Keyboard input support

### Excluded

- Scientific calculations
- Graphing functionality
- User accounts
- Calculation history synchronization across devices

## Functional Requirements

### RQ-001

The application shall run entirely within a modern web browser.

### RQ-002

The application shall provide number buttons from 0 through 9.

### RQ-003

The application shall support addition (+).

### RQ-004

The application shall support subtraction (-).

### RQ-005

The application shall support multiplication (×).

### RQ-006

The application shall support division (÷).

### RQ-007

The application shall support decimal values.

### RQ-008

The application shall display entered values and calculation results in a
visible display area.

### RQ-009

The application shall provide a clear (C) function that resets the current
calculation.

### RQ-010

The application shall provide a backspace/delete function for removing the most
recently entered character.

### RQ-011

The application shall calculate and display results when the equals (=) button
is selected.

### RQ-012

The application shall support keyboard input for numbers, operators, Enter,
Backspace, and Escape.

### RQ-013

The application shall provide both Light Mode and Dark Mode themes.

### RQ-014

The application shall persist the user's selected theme between browser
sessions.

### RQ-015

The application shall present a responsive layout that functions correctly on
desktop, tablet, and mobile screen sizes.

## Non-Functional Requirements

### NFR-001

The application shall load within 2 seconds on a typical broadband connection.

### NFR-002

The user interface shall be usable at viewport widths as small as 320 pixels.

### NFR-003

Buttons shall provide visible hover and focus states.

### NFR-004

Text shall maintain sufficient contrast in both dark and light themes.

### NFR-005

The application shall not require user authentication.
