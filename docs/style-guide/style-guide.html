02 · Foundations

Color, from tokens only.

Five groups, each with a job. A value has no meaning until the group it belongs to is known — which is why raw hex never appears in markup, and why a theme is one block of remaps.

Surface

bg · bg-2 · panel · panel-2 · raise

Elevation is a step in lightness, not a shadow. Shadows are reserved for things that genuinely float: toasts, popovers, drag handles.

--bgpage canvas
--bg-2inset wells
--panelcard floor
--panel-2card top · chips
--raisehover · floating

Panels use linear-gradient(180deg, var(--panel-2), var(--panel)) — a 2% lift that reads as a lit surface without a shadow.

Line

three weights only
--line1px dividers
--line-2control borders
--line-3hover · emphasis

If a layout seems to need a fourth weight, the fix is hierarchy or spacing — not another hex.

Ink

text · muted · dim

Primary — --text · the only color for content you must not miss

Secondary — --muted · supporting copy, table cells, the floor for body text

Tertiary — --dim · non-essential labels only; never the sole carrier of meaning

Assign ink by role, not by size. Metadata is 12.5px mono in --dim; nothing smaller than 12.5px, ever.

Accent

one brand hue
--accentfills · one per view
--accent-inkaccent text · icons
--accent-dimborders · inactive
--on-accenttext on the fill

The flat accent is #D4AF37, the Rush console gold. The mark uses a separate four-stop metallic gradient and is not a second brand color. The fill is theme-invariant; only its contrast context remaps per theme. Gradients stay on the mark: never on a data mark, never to fake elevation.

Status

ok · info · warn · danger

Status colors carry hue. Severity is a separate, four-tier rubric, and it always pairs color with a written label.

passing queued degraded failing neutral featured

Tints are plain alpha tokens — 12% fills and 45% borders — remapped in the light theme. No color-mix.

Do

Let a surface get quieter as data gets denser. Put the accent on the single most important action, metric, or threshold and let everything else be line and ink.

Don't

Add a sixth status hue, tint a whole panel with a status color, or use the accent for destructive actions. Danger owns destruction; the accent never does.

Two ramps, one measure.

A display ramp for structure and a UI ramp for work. Everything is 600 weight or lighter — density comes from size and color, never from bold.

Measure & families

prose 700px · 60–72ch

Prose caps at 700px (≈72ch). Past that, line breaks stop being predictable and scanning cost climbs.

Mono is for code, IDs, timestamps, counts, and uppercase labels — never for paragraphs. Two families, both system stacks, so nothing blocks first paint.

Display & UI

Sentence case everywhere except mono labels. Numbers get units, not decoration: 84 ms, 412 / 600 GB, 99.94% — a space before the unit, no space before %.

04 · Foundations

A 4px grid, six radii.

Every value is a multiple of 4. Whitespace is a token, not a taste — which is the only way spacing stays consistent across four people building the same screens.

Scale

steps are tokens, not literals
--s-1 · 4icon ↔ label gap
--s-2 · 8chip padding-y
--s-3 · 12table cell x · grid gap
--s-4 · 16field padding · block gap
--s-5 · 24card padding · prose rhythm
--s-6 · 32panel padding
--s-7 · 48section rhythm · page gutter
--s-8 · 64major splits

Off-grid values are allowed only in two places: hairline borders (1px) and optical nudges. Every padding, gap, and margin in this file is a --s-* step.

Radii

inner < outer, always
--r-1 · 2
microkbd · skeleton · small buttons
--r-2 · 4
controlinputs, buttons, selects
--r-3 · 6
platewells · kpi · code · empty
--r-4 · 8
cardcallouts · toasts · swatches
--r-5 · 10
panelcards · specs · panels
--r-6 · 999
pillchips · tags · switches

Nested radii subtract 2 at each level — a --r-5 panel containing an --r-3 well reads as concentric. Circles stay 50%. Every other corner uses these tokens.

Layout grid

Content caps at 1320px with a 48px gutter. Columns are 3-up on desktop, 2-up at 1100px, 1-up at 720px. Prose never exceeds 700px, so reading measure stays comfortable even when the grid widens.

Density

Control height is fixed at three sizes: 32px small, 40px default, 48px large. Dense tables drop to 28px rows via .tbl.dense. Density is chosen per surface, never inherited by accident.

05 · Components

Every pattern includes states.

These are the minimal building blocks for dense work — buttons, inputs, choices, chips, severity, callouts, tables, navigation, KPIs, meters, empty/loading, toast, and the mark slot. Every control has focus, disabled/readonly, and error/loading specified.

Buttons

4 variants · 3 sizes

Focus ring is a 2px outline in --accent with 2px offset. Primary buttons use a small top-to-bottom gradient over the accent to preserve legibility; never a brand rainbow. Destructive actions are only .danger, never primary.

Fields, select, textarea

labels above · help & error
Help text explains why you're asked for this.
A valid name is required.
Use native <select> where possible — it matches platform a11y and density with no JS.
Textarea respects line height and wraps at the prose measure in forms.

Controls are 40px default height, bordered in --line-2, filled --panel-2, with focus state moving border to --line-3 and outline on focus-visible. .bad uses --danger for border and text.

Choice controls

checkbox · radio · switch

These are native checkbox, radio, and switch inputs. The accent fills the checked state. The switch animates the thumb only. The visual mark stays 16–18px; the hit target is 40px.

06 · Data

One rubric for severity, one grammar for data.

Status colors say what kind of thing happened. Severity says how much it matters. Keeping those two axes separate is what stops dashboards from turning into a wall of orange.

Severity rubric

four tiers · label required
Critical

Data loss, security exposure, or a full outage. Page someone. Act now.

p95 latency > 30 s · disk full · auth outage

High

Core workflow broken or degraded for many users. Fix today.

p95 > 5 s · > 5% of requests failing · queue stalled

Medium

Degradation with a workaround, or a trend heading the wrong way.

p95 > 1 s · retry rate climbing · cache misses up

Low

Informational. Record it, review later, do not interrupt anyone.

new deploy · quota at 60% · cert expires in 21 d

The tier is set by impact, not by how alarming the text sounds. Color, icon, and written label always ship together — a color-only signal is not accessible.

Do

Show the number, its unit, its boundary, and where it came from. Put the threshold label next to the bar. Reserve red for things that are actually broken.

Don't

Color a healthy metric red because it went down, flag a value without stating the threshold, or mix severity and status on the same row.

07 · Behavior

Motion that confirms, never performs.

In a dense tool, animation has one job: tell you what changed. Everything that moves is a state transition, and every one of them respects prefers-reduced-motion.

Timing

two durations · one easing
Duration
TokenValueUse
--dur-1150msHover, focus, color, border
--dur-2220msPanels, dialogs, toasts, drawers

A single easing, ease, for everything. Nothing bounces, springs, or overshoots — overshoot on a data tool reads as noise.

What earns motion
ElementMotion
Buttons, chips, rowsbackground / border tint, 150ms
Switch thumbtranslate, 150ms
Toastfade + 6px rise, 220ms
Skeleton, spinnerloop, until resolved
Numbersno animation — update in place

Tab underline, tooltip opacity, and nav tint all animate at --dur-1. Nothing animates on scroll; only the rail highlight changes.

Loading

spinner inside the control that triggered it
inline · 14px · 0.8s loop

Disable the button that triggered the action, show the spinner inside it, and keep its width stable so the row doesn't reflow. For anything over ~2s, add a line of text with the elapsed state rather than a faster spinner.

Reduced motion

the rule, not an exception
/* Loops only when motion is welcome. */
@media (prefers-reduced-motion: no-preference) {
  .flow    { animation: flow 1.6s linear infinite; }
  .spinner { animation: spin .8s linear infinite; }
}

/* Transitions collapse; nothing fades through the frame. */
@media (prefers-reduced-motion: reduce) {
  html { scroll-behavior: auto; }
  *    { transition-duration: .01ms !important; }
}

Infinite loops are wrapped in no-preference so they simply never start. State changes still happen — they're just instant. Skeleton shimmer is off by default for the same reason.

Icons

one stroke, 1.6px, 24px grid
grid table form mobile doc search filter gauge terminal cloud lock shield

Icons inherit currentColor, so they recolor with the text they sit next to — no separate icon palette. Use aria-hidden when the icon repeats adjacent text, and .ico inside buttons to keep the 15px size consistent.

Composition rules

same in all six

Structure

Page title and primary action share one row. A toolbar sits directly above the thing it filters. Panels never nest more than two deep.

One accent fill per view region. Secondary actions are ghost or default; destructive actions are .danger and never the default focus.

Responsive

Grids collapse at 1100px and 720px. Code and comfortable tables may scroll inside their own container. Below 720px, .tbl.dense stacks each cell and labels it from data-label.

The section rail is a convenience and disappears under 1100px — it's never the only navigation. Touch targets stay at 40px+ in every shape.

09 · Adoption

Copy the system, not one block.

There is no build step, no package, and no framework requirement. A working screen needs the :root tokens, the light-theme remap, the component classes, the SVG symbols, the responsive rules, and the script. Inline style attributes in this file are specimen layout. Do not extract them into production components.

Tokens first

then classes, symbols, rules, script
/* 1. Tokens — the single source of truth. */
/* 1. surface — elevation is lightness, not shadow */
:root {
  --bg: #07080A; --bg-2: #0B0C0E; --panel: #0E0F12;
  --panel-2: #121418; --raise: #191B20;

  /* 2. line — three weights, no more */
  --line: #23262C; --line-2: #2E3138; --line-3: #3A3D44;

  /* 3. ink — role, not size */
  --text: #ECEAE4; --muted: #9A988F; --dim: #63625D;

  /* 4. accent — the fill is theme-invariant */
  --accent: #D4AF37; --accent-ink: #F2D168;
  --accent-dim: #6E5B22; --on-accent: #0B0C0E;

  /* 5. status — hue only; severity is the rubric */
  --ok: #7FB99A; --info: #74A9E0;
  --warn: #E8943F; --danger: #E5534B;

  /* space · radius · motion */
  --s-1: 4px; --s-4: 16px; --s-7: 48px;
  --r-2: 4px; --r-5: 10px; --r-6: 999px;
  --dur-1: 150ms; --dur-2: 220ms; --ease: ease;
}

/* 6. Theme — a remap, never a redesign. */
html[data-theme="light"] {
  --bg: #F6F4EF; --panel: #FFFFFF; --panel-2: #FBFAF6;
  --text: #15171B; --accent: #D4AF37; --accent-ink: #7A5F0E;
}

/* 7. Accessibility — loops only when motion is welcome. */
@media (prefers-reduced-motion: reduce) { * { transition-duration: .01ms !important; } }

Light and dark share one structure. Surface and status tints are remapped in the light block; component rules do not fork.

Before you ship

  • No raw hex in markup — every color traces to a token.
  • Both themes pass contrast at body, muted, and dim text.
  • Every interactive element is a native control with a visible focus state.
  • Status and severity always ship a written label.
  • Empty, loading, and error states exist for every data view.
  • Numbers that change in place use tabular numerals.
  • Layout holds at 720px without horizontal scroll.
  • Infinite animations wrapped in no-preference.

Where it pays off

  • A drawn span standing in for a checkbox, switch, tab, or nav row.
  • A one-off hex in a component that "needs its own shade."
  • A second shadow system layered on top of lightness elevation.
  • A new status hue added because a label needed to stand out.
  • A spinner standing in for an empty or error state.
  • Skipped empty states because "there won't be data."

Consistency is a feature.
